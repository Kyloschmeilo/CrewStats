Neu in 1.3.0:

- Rollenwünsche: Mit /rollenwunsch wünschst du dir im Discord eine Rolle für deine nächste Runde (20 XP, 2× pro Spieleabend). Admins können mit /rolle-zuweisen Rollen festlegen.
- Der Host schreibt vor dem Start offen in den Chat, wie viele Rollen per Discord kommen. Anzahl Impostor und Spezialrollen bleiben wie eingestellt; klappt ein Wunsch nicht, gibt es die XP zurück.
- Abschalten als Host: in der Config `[Rollenwuensche] Enabled = false`.

Wer die Mod schon hat: wird beim nächsten Spielstart automatisch aktualisiert.
